# Java + DSA Refresher for LeetCode

**Read online:** https://maskedsyntax.github.io/java-interview-handbook/

Open [`index.html`](index.html) in any modern browser. It is a standalone, offline handbook: the JetBrains Mono font, styling, diagrams, Java highlighting, and interaction scripts are embedded in the file.

Use the chapter filter (`/`), light/dark switch, code copy buttons, and locally saved chapter checkboxes while working through LeetCode Top Interview 150. Start with the Java reference and revisit the algorithm chapters as needed.
